ボタンの作り込み

押せるものが「押せそうに見えて、押した瞬間に返事をする」ところまで決めます。実際にカーソルを乗せて／押して確認できます。主ボタンには内側1pxのハイライトと薄い影を入れ、平らなカードから1段浮かせました（既存の画面にも反映済み）。

5種類だけ 1画面に主ボタンは1つ。それ以外は副・控えめ・破壊的から選びます。
