# 応援機能

## 決定事項

- 支払いには Stripe の Checkout を使い、Stripe の支払いページに移って支払う
- 入口はアカウントメニューの「応援する」だけにする
- 金額は、アプリの別のページで 300 円、500 円、1000 円、金額を指定 の 4 つから選ぶ
- 「金額を指定」のときは、そのページで金額を入力する
  入力できるのは 100 円から 10,000 円までで、アプリのサーバーでも範囲を確かめる
- Stripe の支払いページでは、アプリで決めた金額をそのまま支払う
- アプリは金額や支払いの結果を保存しない。支払いの記録は Stripe の管理画面に残る

## 流れ

1. アカウントメニューで「応援する」を押す
2. 金額を選ぶページに移り、金額を選ぶか入力する
3. アプリのサーバーが、選んだ金額で Stripe に支払い（Checkout Session）を作る
4. Stripe の支払いページに移り、カード番号などを入力して支払う
5. 支払いが終わると、お礼のページに移る
6. お礼のページのサーバーが、Stripe に支払いの状態を問い合わせる。
   支払いが終わっていればお礼を表示し、終わっていなければ金額を選ぶページに戻す
